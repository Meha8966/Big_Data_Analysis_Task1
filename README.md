## Task Description

The objective of this task is to perform big data analysis using PySpark on a large sales dataset. The task involves loading and processing the dataset, analyzing sales-related information, and generating meaningful insights using PySpark operations. Various data processing techniques such as schema inference, descriptive statistics, grouping, aggregation, and data exploration are used to demonstrate the scalability and efficiency of big data tools. The analysis helps in understanding sales trends, product performance, order status distribution, and country-wise sales contribution.
